# Judo Ceremony Desk v0.23.6 Preview

**Appearance… → Background presets → Premium judo · Crimson** adds another square background, with subtle abstract throwing silhouettes, crimson-to-burgundy gradients and restrained gold accents.

For a square staff export, choose **Image ratio → Square (1:1)**. The existing Wide and Square artwork options are also available. Selected artwork is embedded in the event file.

Close the older app and launch **Start Judo Ceremony.cmd**, which selects **dist/JudoCeremony-0.23.6/JudoCeremony.exe**.

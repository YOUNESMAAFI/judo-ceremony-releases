# Judo Ceremony Desk — short demonstration

Use the **0.20.3** build. The purpose of the demonstration is to show one clear route from competition data to staff preparation and the audience screen.

1. **Connect and update.** Click Update event in the top bar. Enter the official IJF competition link once and select its category group. Point out the saved Last updated time and connection badge. The same update feeds every workspace.
2. **Choose today's podium.** Open Final block and select Today or the relevant competition day. Use Fetch category for a quick check of this category only, or Update event for the whole competition. Explain the colours: green means four usable medal entries; grey means partial or no results. Review the countries and athlete names before choosing Prepare selected podium.
3. **Show the staff image.** Preparation displays the flag positions, event/category and optional result recap. Copy image can be pasted directly into the staff's chosen application. Medal countries can also be entered manually.
4. **Run the ceremony.** Open Ceremony display, select the HDMI screen and load the prepared podium. Play, Pause, Restart and Black screen operate the loaded ceremony. An event update does not replace it. Athlete names stay off the audience screen.
5. **Show the social output.** Open Create social post. Select the category, create/edit a post and choose one of the four layouts. The latest published top eight are supplied automatically from Update event; no separate apply step is needed. Export a PNG. Valid edits and designs are remembered per event and category.
6. **Show supporting tools if asked.** Tools contains Event history, Anthem testing and Event readiness. Event contains New event, Open/Save tournament and portable backups. Countries controls regional and participation filters.

For a rehearsal, identify demonstration results as fictional. For a live event, review published medals with officials and rehearse the HDMI display and venue speakers. Anthem playback is still beta. A successful software check does not replace that venue rehearsal.

When sharing this build, send the whole app folder or ZIP. Version 0.20 saves schema-9 events; use 0.20 or newer to reopen them.

## Run on Windows

1. Extract the entire Windows ZIP to a local folder. Keep its Assets, Notices, examples and docs folders together.
2. Open JudoCeremony.exe. The Windows x64 package includes .NET and works offline.
3. On Preparation, enter the tournament name, choose a category and assign the medal countries using three-letter codes. Copy the staff image or save a PNG.
4. For an audience screen, connect HDMI, use Windows Extend mode and choose that monitor on Ceremony display. Load the preparation, then use Play, Pause, Restart, Reset or Black screen.
5. Use Show on screen to choose titles, flags, codes, country names, medal labels, results table, hashtag and logos.

The package includes sample tournaments and documentation. Close older versions before launching this build.

## Preview status and audit

Version 0.7.0 is a preview for review and rehearsal. Its 149 software checks and native Windows package checks passed. Rehearse on the actual event computer and HDMI display before live use. Anthem audio playback remains deferred.

The audit covers all 255 catalog countries in both orientations. Artwork for 221 countries is backed by the April 2026 IJF manual or original workbook; 34 entries require organizer review. Special delegation gaps and remaining differences are documented in the searchable PDF. The newer IJF manual takes priority when it disagrees with Excel.
